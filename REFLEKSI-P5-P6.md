Pada pertemuan 5, saya mempelajari cara membuat form pendaftaran menggunakan HTML dan PHP. Saya memahami bahwa atribut `name` digunakan sebagai key data yang dikirim ke PHP, sedangkan `id` digunakan untuk menghubungkan label dengan elemen form. Selain itu, saya belajar membuat tampilan form yang responsif agar dapat digunakan pada perangkat desktop maupun mobile.

## Pertemuan 6

Pada pertemuan 6, saya mempelajari branching dan looping dalam PHP. Branching digunakan untuk menentukan keputusan berdasarkan kondisi, sedangkan looping digunakan untuk mengulang data. Saya menggunakan `if` untuk menentukan kondisi peserta dan diskon, serta `foreach` untuk menampilkan data kursus, minat, dan riwayat pendaftaran dari array. Saya juga membuat test matrix untuk memastikan fitur berjalan sesuai yang diharapkan. Dari pertemuan ini, saya semakin memahami cara membuat program PHP yang lebih terstruktur dan mudah dikembangkan.
